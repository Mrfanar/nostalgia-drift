NOSTALGIA DRIFT — как выложить игру на GitHub Pages и поставить на телефон
==========================================================================

Что в папке
-----------
index.html            — сама игра
manifest.webmanifest  — описание приложения (название, иконка, горизонтальный экран)
sw.js                 — офлайн-кэш: после первого запуска игра открывается даже без интернета
icon-*.png, apple-touch-icon.png — иконки
s15.b64.txt           — 3D-модель машины
red_*.jpg, black_*.jpg — ливреи MrFanar и VIRUS

1. Выложить на GitHub Pages (один раз, бесплатно)
-------------------------------------------------
1) Зарегистрируйся на https://github.com (если ещё нет аккаунта).
2) Нажми «+» вверху справа → «New repository».
   • Repository name: nostalgia-drift (или любое имя латиницей)
   • Выбери «Public»
   • Нажми «Create repository».
3) На странице нового репозитория нажми ссылку «uploading an existing file».
4) Перетащи в окно ВСЕ файлы из этой папки (не саму папку, а файлы внутри неё).
   Дождись, пока загрузится s15.b64.txt (около 10 МБ), и нажми «Commit changes».
5) Открой вкладку «Settings» → слева «Pages».
   • Source: «Deploy from a branch»
   • Branch: «main», папка «/ (root)» → «Save».
6) Подожди 1–2 минуты и обнови страницу настроек: вверху появится адрес вида
   https://ТВОЙ-НИК.github.io/nostalgia-drift/
   Это и есть ссылка на игру. Её можно отправить другу.

2. Поставить на Android как приложение
--------------------------------------
1) Открой ссылку в Chrome на телефоне и дождись загрузки игры.
2) Нажми меню «⋮» справа вверху → «Установить приложение»
   (или «Добавить на главный экран»).
3) На рабочем столе появится иконка «Nostalgia Drift». Игра будет открываться
   на весь экран, сразу горизонтально, без адресной строки.

На iPhone: открой ссылку в Safari → кнопка «Поделиться» → «На экран «Домой»».

3. Как обновить игру потом
--------------------------
1) В репозитории нажми «Add file» → «Upload files» и загрузи новые файлы поверх старых.
2) В файле sw.js поменяй строку  const VERSION = 'nostalgia-drift-v6';  на 'nostalgia-drift-v7' (потом v8 и т.д.),
   иначе телефоны могут показывать старую версию из кэша.
3) На телефоне закрой и снова открой игру (иногда нужно открыть два раза).

4. Игра вдвоём
--------------
• Работает только когда игра открыта по ссылке с GitHub Pages (в превью Claude
  подключение может не пройти). Нужен интернет на обоих телефонах.
• Один нажимает «Вдвоём» → «Создать» и отправляет другу 4-значный код.
• Второй нажимает «Вдвоём», вводит код → «Войти».
• Каждый выбирает свою машину, трассу выбирает тот, кто создал комнату.
• Машины проезжают друг сквозь друга (без столкновений), очки соперника видны
  вверху, в конце трассы — кто победил.

Важно
-----
• Рекорды и имя игрока хранятся в памяти браузера на каждом телефоне отдельно.
  Общую таблицу рекордов для двух телефонов можно сделать через бесплатную онлайн-базу
  (например, Firebase) — это отдельный шаг.
